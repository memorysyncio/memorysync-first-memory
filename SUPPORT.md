# Support

Before requesting help:

1. Follow the [first-memory guide](https://docs.memorysync.io/first-memory).
2. Confirm the environment variables in `README.md` are set server-side.
3. Review [authentication](https://docs.memorysync.io/api/authentication).
4. Reduce the problem to a minimal, sanitized cURL, Python, or TypeScript example.

Use the [MemorySync contact route](https://memorysync.io/enterprise-contact) for support questions. Include your runtime version, example release, expected result, actual result, and a sanitized reproduction.

Never include API keys, customer data, private logs, account identifiers, or proprietary prompts. No support SLA is established by this repository.

For suspected vulnerabilities, use the private reporting route in `SECURITY.md`.
