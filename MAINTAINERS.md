# Maintainer policy

The official MemorySync GitHub account is [`memorysyncio`](https://github.com/memorysyncio), the official platform source repository is `memorysyncio/memorysync-platform`, and `@memorysyncio` is the default code owner and release maintainer for this starter.

Before the standalone starter release, MemorySync must:

- use the standalone repository at `memorysyncio/memorysync-first-memory`;
- protect the default branch, disable force pushes, and require the starter validation workflow;
- enable secret scanning, push protection, and dependency/security alerts;
- define repository access, review, release, and security-advisory permissions.

Maintainers keep canonical Docs/package links current, review dependency updates, triage sanitized issues, and publish release notes. Unsupported claims, generated link campaigns, secrets, internal ownership details, and unrelated product behavior are outside this repository's scope.

The official repository is protected by required validation and security controls. Evidence for the initial public release is retained in the MemorySync Week 4 SEO archive.
