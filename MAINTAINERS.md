# Maintenance

This starter is maintained through MemorySync's official GitHub account, [`memorysyncio`](https://github.com/memorysyncio).

Maintenance includes:

- keeping examples aligned with released SDKs and canonical documentation;
- reviewing dependency and security updates;
- triaging reproducible, sanitized issues;
- requiring the `validate` workflow before changes reach `main`; and
- publishing release notes for user-visible changes.

Repository security controls include protected branches, dependency alerts, secret scanning, push protection, and private vulnerability reporting. See `SECURITY.md` for the reporting route.
